# REGRAS OBRIGATÓRIAS DO PROJETO
- Sempre leia este arquivo antes de modificar qualquer código.
- Nunca finalize uma tarefa sem rodar todos os testes no terminal e confirmar que 100% passaram.
- Para cada nova funcionalidade ou regra criada, escreva um teste automático validando o resultado esperado.
- Ao corrigir um bug, siga esta ordem: (1) crie um teste que reproduza o erro falhando; (2) corrija o código; (3) rode o teste novo e todos os antigos para garantir que o erro sumiu e nada quebrou.
- Altere apenas os arquivos necessários para o pedido atual, sem mexer no que já está funcionando.
